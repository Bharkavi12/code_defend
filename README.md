A comprehensive, production-style cybersecurity application that combines **deterministic Static Application Security Testing (SAST)** and **Machine Learning (TF-IDF + Calibrated Linear SVM)** to analyze source code for software vulnerabilities, calculate overall security posture scores, explain risks in technical depth, provide automated secure code remediation, and export branded PDF audit certificates.

> **Project Notice**: This system is designed as an educational application security framework and research prototype. It is not intended as a substitute for enterprise commercial SAST suites. Code submitted to this tool is evaluated purely as static text/AST and is **never executed**.

## 1. Project Overview

The **AI-Powered Source Code Vulnerability Detection & Explanation System** addresses the critical gap in developer-focused application security: identifying code vulnerabilities early in the software development lifecycle (SDLC) while explaining the underlying root cause and providing actionable, language-specific remediation code.

Unlike simple pattern matchers or opaque black-box AI tools, this system implements a **transparent hybrid fusion engine**:
* **Deterministic Static AST & Pattern Rules**: Pinpoints exact line numbers, syntax patterns, and dangerous function calls.
* **Calibrated Statistical Machine Learning Classifier**: Computes multi-class probability vectors across unigram/bigram token distributions.
* **Result Fusion Engine**: Corroborates dual-source evidence using a probabilistic union model.
* **Explainability & Remediation Engine**: Generates CWE/OWASP mappings, CIA impact assessments, and side-by-side secure code refactors.

---

## 2. Problem Statement

Developers frequently introduce high-risk vulnerabilities such as SQL Injection, Command Injection, Cross-Site Scripting, and Insecure Deserialization due to complex frameworks and insufficient security feedback loops. Traditional static analysis tools often produce high false positive rates and terse, unhelpful error codes.

This system provides:
1. Multi-language vulnerability scanning (Python and JavaScript).
2. Transparent security scores (0–100) with graded risk ratings.
3. Interactive code inspection with line-level vulnerability highlighting.
4. Exportable PDF security audit certificates for compliance tracking.

---

## 3. Key Features

- **Hybrid Detection**: Blends Python AST analysis and JavaScript token regexes with a trained scikit-learn classifier.
- **Line-Level Highlighting**: Visual code viewer flags vulnerable lines directly in the interface.
- **Secret Sanitization**: High-entropy API keys, passwords, and tokens are automatically masked in the UI and PDF reports.
- **Automated Fix Recommendations**: Every finding includes technically verified before-and-after code diffs.
- **Audit Reports**: Instant one-click PDF generation powered by ReportLab.
- **Historical Audit Database**: Full SQLite persistence tracking scan history, findings, and duration.
- **Live AI Evaluation Dashboard**: Displays genuine metrics, multi-model comparisons, and confusion matrices generated by the training pipeline.

               │
       ┌───────┴───────────────────────┐
       │                               │

       │                               │

                       ▼

                       │

                       │

       ▼                               ▼
SQLITE DATABASE & DASHBOARD     REPORTLAB PDF AUDIT

## 7. Installation & Windows Setup

### Prerequisites
- Python 3.10+ installed and added to PATH
- Node.js (v18+) and npm installed

### Step 1: Clone Repository & Setup Backend

```powershell
# Navigate to project root
cd AI-Code-Security-Analyzer

# Navigate to backend directory
cd backend

# Create and activate virtual environment
python -m venv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Train and evaluate ML models (generates metrics.json & model artifacts)
python ml/train.py

# Run backend automated test suite (24 tests)
pytest tests/ -v

# Start the Flask API server (runs on http://localhost:5000)
python app.py
```

### Step 2: Setup and Start Frontend

In a separate terminal:

```powershell
# Navigate to frontend directory
cd AI-Code-Security-Analyzer/frontend

# Install node dependencies
npm install

# Start Vite development server (runs on http://localhost:5173)
npm run dev
```

Open your browser and navigate to `http://localhost:5173`.

## 12. Security & Threat Considerations

* **Zero-Execution Architecture**: Submitted source code is parsed exclusively as data/text streams using Python's `ast.parse` and regex tokenization. The system strictly avoids `eval()`, `exec()`, or invoking system shells on user code.
* **Secret Masking**: Any detected hardcoded passwords or API tokens are masked (e.g. `sk_live_****1234`) to prevent credential leakage.
* **Input Validation**: Request payload sizes are limited to 200 KB to mitigate resource exhaustion attacks.
* **Database Isolation**: Foreign key constraints with cascading deletes ensure integrity.
